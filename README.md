# 🚀 Meu Portfólio Profissional

Seja bem-vindo(a) ao repositório do meu Portfólio Pessoal e Profissional! Este projeto foi desenvolvido com tecnologias modernas de desenvolvimento web para apresentar meus projetos, habilidades técnicas, trajetória profissional e canais de contato de forma interativa, responsiva e elegante.

---

## 💻 Tecnologias Utilizadas

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Biblioteca**: [React 19](https://react.dev/)
- **Linguagem**: [TypeScript](https://www.typescriptlang.org/)
- **Estilização**: Tailwind CSS & Glassmorphism UI
- **Ícones**: [Lucide React](https://lucide.dev/)
- **Hospedagem & CI/CD**: [Vercel](https://vercel.com/)
- **Controle de Versão**: [GitHub](https://github.com/)

---

## 🎨 Funcionalidades

- **Design Responsivo**: Experiência fluida em computadores, tablets e smartphones.
- **Modo Escuro e Claro**: Alternância dinâmica de tema com preferência do usuário.
- **Showcase de Projetos**: Apresentação interativa de projetos com links para repositórios e demonstrações ao vivo.
- **Habilidades & Tecnologias**: Filtros por categorias (Front-end, Back-end, Ferramentas e Mobile).
- **Formulário de Contato**: Interface para envio de mensagens com validação visual.
- **Links Sociais**: Acesso rápido ao GitHub, LinkedIn e E-mail.

## 🚀 Como Executar Localmente

1. **Clone o repositório**:
   ```bash
   git clone <URL_DO_REPOSITORIO>
   cd Portifolio
   ```

2. **Instale as dependências**:
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento**:
   ```bash
   npm run dev
   ```

4. **Acesse no seu navegador**:
   Abra [http://localhost:3000](http://localhost:3000) para visualizar o projeto.

## 🌐 Deploy na Vercel

O projeto está configurado para deploy contínuo na Vercel. Qualquer push realizado no branch `main` atualizará automaticamente a versão em produção.

Para realizar o deploy via linha de comando:
```bash
npx vercel
```
